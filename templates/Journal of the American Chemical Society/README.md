# Journal of the American Chemical Society

JACS 投稿模板（achemso，ACS 期刊样式）。

## 使用

1. 解压本压缩包到任意目录。
2. 打开 `main.tex`，按模板注释填写标题、作者、摘要与正文。
3. 使用 LaTeX（pdflatex 或 xelatex，视模板要求）编译。

## 来源与许可

- 许可：LPPL-1.3c

## 说明

achemso 文档类目前主要保留用于历史兼容；投稿前请核对 ACS 最新的作者指南与模板要求。
