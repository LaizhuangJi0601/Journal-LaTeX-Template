# Springer Nature Journals (Generic)

Springer Nature 期刊通用 LaTeX 模板（sn-jnl）。

## 使用

1. 解压本压缩包到任意目录。
2. 打开 `main.tex`，按模板注释填写标题、作者、摘要与正文。
3. 使用 LaTeX（pdflatex 或 xelatex，视模板要求）编译。

## 来源与许可

- 来源：https://www.springernature.com/gp/authors/campaigns/latex-templates
- 许可：LPPL-1.3c
- 版权归原发布者所有；本包仅为作者投稿提供便利。

## 说明

sn-jnl 适用于 Springer Nature 多数期刊；具体期刊可能要求不同的参考文献样式与章节结构。
