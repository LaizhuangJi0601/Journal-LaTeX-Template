# Measurement (Elsevier)

Measurement（Elsevier）投稿模板；基于 elsarticle 数字引用样式。

## 使用

1. 解压本压缩包到任意目录。
2. 打开 `main.tex`，按模板注释填写标题、作者、摘要与正文。
3. 使用 LaTeX（pdflatex 或 xelatex，视模板要求）编译。
