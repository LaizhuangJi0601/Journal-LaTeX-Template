# Elsevier Journals (Generic)

Elsevier 期刊通用 LaTeX 模板（elsarticle，数字引用样式）。

## 使用

1. 解压本压缩包到任意目录。
2. 打开 `main.tex`，按模板注释填写标题、作者、摘要与正文。
3. 使用 LaTeX（pdflatex 或 xelatex，视模板要求）编译。

## 来源与许可

- 来源：https://ctan.org/pkg/elsarticle
- 许可：LPPL-1.3c
- 版权归原发布者所有；本包仅为作者投稿提供便利。

## 说明

适用于 Elsevier 多数期刊；不同期刊的摘要、关键词、参考文献与图形要求可能不同。
