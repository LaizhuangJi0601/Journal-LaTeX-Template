# IEEE Sensors Journal

IEEE Sensors Journal 投稿模板；基于 IEEEtran journal 模式，附期刊要求说明。

## 使用

1. 解压本压缩包到任意目录。
2. 打开 `main.tex`，按模板注释填写标题、作者、摘要与正文。
3. 使用 LaTeX（pdflatex 或 xelatex，视模板要求）编译。

## 来源与许可

- 来源：https://ctan.org/pkg/ieeetran
- 许可：LPPL-1.3c
