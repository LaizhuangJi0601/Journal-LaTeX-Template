# Physical Review Letters

Physical Review Letters 投稿模板（REVTeX 4.2，APS PRL）。

## 使用

1. 解压本压缩包到任意目录。
2. 打开 `main.tex`，按模板注释填写标题、作者、摘要与正文。
3. 使用 LaTeX（pdflatex 或 xelatex，视模板要求）编译。

## 来源与许可

- 来源：https://ctan.org/pkg/revtex
- 许可：LPPL-1.3c
- 版权归原发布者所有；本包仅为作者投稿提供便利。

## 说明

本包使用 REVTeX 4.2 的 APS PRL 模板；PRL 对篇幅、摘要和补充材料有额外要求，请核对 APS 官网。
