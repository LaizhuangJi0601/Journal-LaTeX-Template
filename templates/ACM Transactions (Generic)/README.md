# ACM Transactions (Generic)

ACM Transactions/Journals 通用 LaTeX 模板（acmart manuscript 模式）。

## 使用

1. 解压本压缩包到任意目录。
2. 打开 `main.tex`，按模板注释填写标题、作者、摘要与正文。
3. 使用 LaTeX（pdflatex 或 xelatex，视模板要求）编译。

## 来源与许可

- 来源：https://ctan.org/pkg/acmart
- 许可：LPPL-1.3c
- 版权归原发布者所有；本包仅为作者投稿提供便利。

## 说明

投稿时按目标 ACM 期刊/会议选择 acmart 选项；本包使用 manuscript 样例。
